# 乔巴 · 录音笔记 (Realtime Chopper)

[English](README.md) | 简体中文

---

## 名字
**乔巴 (Realtime Chopper)** 名字取自《海贼王》中的托尼托尼·乔巴——作为既通晓动物语言又通晓人类语言的驯鹿，天然是最好的“翻译官”。

这是一个运行在浏览器中的**零后端、高隐私、即开即用的实时语音同传翻译网页应用**。所有语音识别均在本地浏览器内部完成，录音数据不出本地。

## 功能
- **端侧本地语音识别**：借助 WebGPU / WASM 在浏览器内直接推理（英文使用 Moonshine Base 约 62MB，中/韩语共用 SenseVoice Small int8 约 240MB；手机上装不下 240MB 时，韩语会自动改用约 64MB 的 Moonshine 韩语模型）。模型初次载入后保存在本地缓存，识别过程离线运行。
- **多通道翻译与自动容灾**：默认使用 Google 翻译，失败时自动平滑切换至微软翻译兜底，同时支持配置自定义 AI / LLM 翻译 API Key。
- **实时双栏对照呈现**：左栏原文、右栏译文实时逐句对齐滚动，移动端竖屏自动切换为上下对照布局。
- **自适应实时朗读 (TTS)**：默认调用浏览器原生语音合成接口边翻边读；面对快速输入时自动动态倍速（最高 1.8x），确保队列不掉句、不积压。可在设置里切换到 **Edge TTS 代理** 引擎，用你自己的代理读微软的在线神经音色，各平台声音一致。
- **录音时屏幕不会自己锁上**：手机上屏幕一锁，页面就被冻住、麦克风跟着被系统收走，而上课时没人会去碰屏幕。现在录音期间会持有一把屏幕常亮锁（Safari 16.4 起，加到主屏幕的应用要 iOS 18.4 起），每次回到前台都会重新申请一次；系统拒绝时（低电量模式）日志会说明并给出该改的那个设置。万一屏幕还是黑过一次，这一场要么带着一个说清楚的缺口继续，要么干净停下，不会假装还在录。
- **打开着的应用也会自己更新**：Service Worker 只在导航时才会去拿新外壳，而 iOS 挂着的应用可以几天不导航 —— 于是手机跑着旧版、线上却看不出任何问题（「屏幕常亮没生效」有可能就是旧版）。现在页面启动时、每次回到前台、以及开着的时候每 5 分钟都会读一遍服务端 `index.html` 的版本号：空着的时候自己重载，有录音或字幕时只在日志里提醒一句，同一个版本只重载一次。
- **原文/译文可拖动分栏**：中间那条带把手的线按住就能拖（竖屏时它变成横的，键盘用方向键也行），比例记在本机。译文按新旧分**三档**字号 —— 最新一句最大，往下依次变小；行数高度由行高和预留行数决定，所以新句子落地时整个列表不抖。
- **设置分三层，各在各的地方**：每节课会改的（语言、翻译用哪家、朗读引擎与音色）在标题栏和朗读设置里；设一次就不动的（界面语言、图标、录音保存）在设置页；调参用的（识别、AI 模型密钥、语速、日志）在**打开调试模式后**才出现的那一半。
- **起始页**：冷启动先给你一页说明白的地方 —— logo 与名字、一块**预留的加载位置**（模块下载、引擎启动、麦克风授权都报在这里，卡片不会因此移动）、两颗方块卡片：「开始录音」和「历史记录」。录起来的那一刻淡入转录页；模块没装就地装，不弹盖住全屏的对话框。
- **暂停之后有三条路**：底栏那颗按钮写的是「暂停」，按下去先弹出面板：标题栏那个时钟（声纹 + 计时）**放大居中**在这里重画一遍（有个长出来的过渡动画），**故意不带标题栏那颗下载按钮** —— 面板上已经有三个出口，再多一个没字的就成了第四个 —— 下面三颗按钮 —— **保存**（先给你改名字，存进历史并跳过去，最新那条打上「新」标）、**继续录音**、**开启新录音**（把这一场存下来，清空字幕，直接开始下一场）。时长跨暂停接着数，不会从零重来。
- **历史记录（录音笔记）**：每一场存下来的不只是文字 —— 音频（16kHz WAV）+ 识别原文 + 译文一起放进本机 OPFS（`rc-history/`），列表按时间倒序，顶上是一行小标题（`历史记录` + 条数与总大小），**这一页没有返回按钮**：回程走左上角 logo 抽屉，或者直接按手机 / 浏览器的返回键（它退的是真的走过的那一步）。点开一条进详情页（顶上是 `返回` 与 `记录详情`），可以逐句看原文与译文、播放 / 下载那段录音（播放器和下载在同一行）、改名字（日期和定位是字段，改名不会弄丢）。标题自动由**日期 + 时间 + 定位**拼成：定位按「浏览器定位 → 反向地理编码 → 时区推断」三级回退。删除走手机相册那条路：`选择` 批量勾选 + 确认框。
- **返回键一次关一层**：打开着的每一屏、每个面板都把自己登记进应用自己的层栈（`lib/app/back.ts`），浏览器历史里就对应着同样多的记录 —— 不多一条。按一下返回只关最上面那一层（弹窗没了、笔记还在），抽屉关掉而底下的页面不动，历史列表回到它**真的**被打开的那一屏；应用自己的 `返回` 按钮走的是同一扇门，关掉时还把自己那条记录也收回去。栈空时应用不占任何记录，返回键就还是系统的返回 —— Android 上即应用退到后台，和别的应用一样。
- **每一屏都有自己的网址**：`/` 是起始页（有录音在跑时就是字幕页），`#/settings` 是设置，`#/history` 是历史列表，`#/history/<id>` 是某一条笔记（`lib/app/route.ts` 是「屏幕怎么拼成字符串」的唯一一处，`lib/app/back.ts` 让地址栏跟着层栈走）。刷新就还落在那一屏上；一条链接 —— 书签、聊天里贴的地址、手机桌面上的快捷方式 —— 直接打开那一屏，哪怕那个页面从来没见过其他屏。返回键从一条链接里退出来的顺序也一样：笔记 → 列表 → 主页。窗口标题也带着屏幕（`记录详情 · 乔巴 · 录音笔记`），标签栏里开着四个也分得清。地址用 `#` 是故意的：这个应用是一个能子路径部署的静态目录，而只有 `#` 后面那段永远不会发给服务器。
- **底栏只放最顺手的三件**：左边录音（录音时按钮**掏空**，麦克风声音在掏空的地方往上漫；那个小方块还是会慢慢胀缩），右边朗读开关（图标是微信语音那种扇形记号，正在读的时候旁边三条柱子跟着跳），以及它左边那颗**朗读设置**（翻译用哪家 / 朗读引擎 / 朗读音色）。启动阶段、部署提醒、麦克风报错这类句子不再占屏幕，全部进日志；正在朗读的那一行，右上角也画着同样三条柱子。
- **标题栏中间是这次录了多久**：左边五条柱子的声纹跟着麦克风动，右边 `mm:ss`。暂停 / 停止后时钟冻住，**声纹和时钟中间出现一颗下载按钮**，把这一场录音存成 `.wav` 拿到手机上（暂停面板上画的那一份不带它）。进设置走左上角 logo 抽屉里那一行，标题栏上不再放设置按钮。
- **两边都能导出文字**：原文栏和译文栏的标题栏各有一颗导出按钮（手机上是一个图标），一句一行导成 `.txt`；没有内容时会在屏幕上说一句，不写空文件。
- **语言选择回到各自的栏里**：「说」在原文栏标题栏上，「译」在译文栏标题旁边（以前都挤在标题栏中间，离两个面板都很远）。
- **麦克风被系统拿走会自动重来**：屏幕亮着时系统也可能把麦克风收回去（来电、别的应用开麦），而这次收回没有任何事件通知。录音期间每秒查一次，连续两次不活着才判定丢失；修不回来就干净停下，并记住这不是人点的停止 —— 回到前台会自动重新开始录音。
- **录音切片与重识回溯**：本地保留当前会话的录音片段，遇识别模糊或异常时，可直接对指定片段发起二次切片重识。
- **三语界面（中文 / English / 한국어）**：整个界面（连日志和诊断报告）跟随浏览器语言自动切换，设置页里可以手动指定，网址后加 `?lang=ko` 也能直接覆盖。
- **纯前端与极简隐私**：无后端、免登录、免配置。支持作为 PWA 安装至主屏幕。仅将识别后的文字传往翻译通道，录音与 API Key 均仅留存在本机。

## 快速开始

### 环境要求
- Node.js 20+
- 支持麦克风权限与 Web Audio 的现代浏览器（Chrome、Edge、Safari、Firefox 等）

### 本地运行
```bash
# 安装依赖
npm ci

# 启动开发服务器
npm run dev

# 端到端测一遍（构建 + 无头 Chrome 真开一次，需要本机 Chrome 和网络）
npm run e2e
```

### 使用说明
1. 打开网页先在**起始页**上看到 logo 和两颗卡片：**开始录音**、**历史记录**。点「开始录音」，首次使用会在这块位置上就地下载本地语音识别模型（下载后长期保存在浏览器缓存中），进度和当前阶段都写在那里。
2. 第一次会问一句「先戴上耳机」（真的戴上再做，否则麦克风会听到手机读译文的声音）。
3. 允许麦克风权限后就开始录了，页面淡入转录与翻译两栏；中途要走开就点底栏左边那颗「暂停」（启动期间它是「取消」）。
4. 暂停后那个面板上选一个：**保存**（收进历史，可先改名字）、**继续录音**、或**开启新录音**（存下这一场并开始下一场）。
5. 以前录的都在**历史记录**里：起始页第二张卡片、或左上角 logo 抽屉里的同一项（抽屉第一行是「主页」，回起始页就是它）；点开一条能看逐句原文 / 译文、回放与下载录音、改名字、批量删除。不想按按钮就用手机 / 浏览器的**返回键**：一次退一层（详情 → 列表 → 来时的屏幕）。
6. 想换语言、换声音、换翻译服务，分别用两栏标题栏上的「说 / 译」和底栏朗读开关旁边的朗读设置钮。

> **注意事项**：
> - 浏览器安全策略要求必须在 `localhost`、`127.0.0.1` 或 `https://` 协议下才允许调用麦克风。
> - 建议佩戴耳机使用，避免扬声器朗读的声音被麦克风循环收录。
